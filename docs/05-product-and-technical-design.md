# Product and technical design

The consolidated implementation plan is in [the SafeArrival system blueprint](07-system-blueprint.md). That document contains the proposed requirements, flows, ERD, UML/sequence diagrams, API contract, security and privacy controls, hosting decisions, and delivery plan.

The design remains provisional until the required interviews are synthesised in [research synthesis](04-research-synthesis.md) and the open decisions in the blueprint are resolved. Do not treat unvalidated assumptions as interview findings.
